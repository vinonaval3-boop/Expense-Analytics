# 📊 Expense Analytics using Python

A data analysis project to track and visualize personal expense patterns using Python, Pandas, Matplotlib, and SQL.

---

## 🛠 Tech Stack
- Python
- Pandas
- Matplotlib
- SQL
- CSV Dataset

---

## 📊 Features
- Data cleaning and preprocessing
- Monthly expense trend analysis
- Category-wise expense breakdown
- Identification of highest & lowest spending category
- Data visualization using line and bar charts

---

## 📈 Output Charts
- 📉 Monthly Expense Trend (Line Chart)
- 📊 Category-wise Expense (Bar Chart)

---

## 🧠 Insights
- Top Spending Category: Shopping
- Lowest Spending Category: Transport
- Helps understand spending patterns and supports better financial decisions

---

## 🚀 How to Run
1. Install required libraries:
```bash
pip install pandas matplotlib
```
2. Run the script:
```bash
python analysis/analysis.py
```
